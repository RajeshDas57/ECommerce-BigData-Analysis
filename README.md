# 🛒 E-Commerce Big Data Analysis

### 📊 Big Data Analytics using Hadoop, MapReduce & Apache Pig

> A practical Big Data project for analyzing large-scale E-Commerce transaction data using distributed storage and processing technologies.

---

## 🔎 What is this Project?

This project analyzes **E-Commerce transaction data** to discover useful information about:

* 💰 Country-wise revenue
* 🛍️ Best-selling products
* 👤 Customer spending
* 📦 Product quantities
* 🌍 Country-wise orders
* ❌ Cancelled transactions

The project demonstrates how a large dataset can be stored in **Hadoop HDFS** and processed using **MapReduce** and **Apache Pig**.

# 📊 Dataset

### Online Retail Dataset

The project uses the **Online Retail Dataset** from the **UCI Machine Learning Repository**.

The dataset contains real-world retail transaction information.

### Important Fields

| Field         | Description                    |
| ------------- | ------------------------------ |
| `InvoiceNo`   | Transaction / invoice number   |
| `StockCode`   | Product code                   |
| `Description` | Product name                   |
| `Quantity`    | Number of products purchased   |
| `InvoiceDate` | Date and time of transaction   |
| `UnitPrice`   | Price per product              |
| `CustomerID`  | Customer identification number |
| `Country`     | Customer's country             |

# 🐘 1. Hadoop HDFS

Hadoop HDFS is used as the distributed storage layer for the E-Commerce dataset.

### Main Tasks

```text
Dataset
   ↓
Create HDFS Directory
   ↓
Upload Dataset
   ↓
Verify Dataset
   ↓
Process Data
```

### Example Commands

```bash
hdfs dfs -mkdir -p /ecommerce/input
```

Upload the dataset:

```bash
hdfs dfs -put OnlineRetail.csv /ecommerce/input/
```

Check the uploaded file:

```bash
hdfs dfs -ls /ecommerce/input
```

# 🐷 3. Apache Pig Analysis

Apache Pig is used for high-level data processing and aggregation.

Instead of writing complex Java programs for every analysis, Pig Latin provides a simpler way to transform and analyze the dataset.

### Main Pig Operations

```text
LOAD
 ↓
FILTER
 ↓
GROUP
 ↓
FOREACH
 ↓
ORDER
 ↓
STORE
```

# 🚀 Running the Project

## Step 1 — Start Hadoop

Run:

```bash
start-dfs.cmd
```

Then:

```bash
start-yarn.cmd
```

Check Hadoop services:

```bash
jps
```

You should see services such as:

```text
NameNode
DataNode
ResourceManager
NodeManager
```

---

# Step 2 — Upload Dataset to HDFS

Create the input directory:

```bash
hdfs dfs -mkdir -p /ecommerce/input
```

Upload the dataset:

```bash
hdfs dfs -put -f OnlineRetail.csv /ecommerce/input/
```

Check:

```bash
hdfs dfs -ls /ecommerce/input
```

---

# Step 3 — Run MapReduce

Go to the MapReduce folder:

```bash
cd mapreduce
```

Compile the Java program according to the Hadoop configuration.

Create the JAR:

```bash
jar -cvf ECommerceMapReduce.jar *.class
```

Run the required MapReduce job:

```bash
hadoop jar ECommerceMapReduce.jar <MainClass> /ecommerce/input /ecommerce/output
```

View the result:

```bash
hdfs dfs -cat /ecommerce/output/part-r-00000
```

---

# Step 4 — Run Apache Pig

Go to the Pig directory:

```bash
cd pig
```

Run a Pig script:

```bash
pig -f <script_name>.pig
```

For example:

```bash
pig -f country_revenue.pig
```

The generated results can then be checked from the configured output location.
